# Profile assets

Original vector artwork for the `skyv26` profile README — Swiss editorial grid, brutalist type, one accent (`#E76F36`).

## Current system (used by README.md)

| Folder | Files | Notes |
| --- | --- | --- |
| `cover/` | `cover-light.svg`, `cover-dark.svg` | Editorial cover with name, positioning and domain index |
| `projects/` | `<slug>-light.svg`, `<slug>-dark.svg` | One concept per project: `crypto-payments`, `hydrogeology`, `edqio`, `genuine-consultancy`, `smile-dmi`, `horovista`, `jewellery-finance`, `ai-systems` |
| `matrix/` | `engineering-matrix-light.svg`, `engineering-matrix-dark.svg` | Capability × project evidence matrix |
| `sections/` | `section-00.svg` … `section-10.svg` | Section bands; orange + neutral grey only, so one file serves both themes |

Light/dark pairs are switched with `<picture><source media="(prefers-color-scheme: dark)">`, which GitHub maps to the viewer's GitHub theme.

Palette: ink `#171717` / paper `#F3F0E8` / muted `#8A8A85` / secondary `#64748B` / accent `#E76F36`.

## Regenerating

All of the above is generated by `build_svgs.py`:

```bash
python3 assets/build_svgs.py .
```

Edit the `PROJECTS`, `SECTIONS` or `ROWS` tables in the script (e.g. to change a status label or an evidence mark), then rerun.

## Legacy

`cover.svg`, `project-*.svg`, `architecture.svg`, `timeline.svg`, `community.svg`, `writing.svg`, `creative.svg` (here and duplicated in the repo root) are the previous illustration set. They are no longer referenced by the README and are kept until you decide to remove them.
