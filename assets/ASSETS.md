# Profile assets

These SVGs are original, lightweight illustrations for the `skyv26` profile README.

- `cover.svg` — editorial header artwork.
- `project-*.svg` — project section illustrations.
- `architecture.svg` — architecture visual.
- `timeline.svg` — engineering journey.
- `community.svg` — mentorship/community visual.
- `writing.svg` — writing section visual.
- `creative.svg` — Skybrel music section visual.

The artwork uses transparent backgrounds, current text colour, and a burnt-orange accent to remain usable in GitHub light and dark themes. GitHub controls the README's actual typography and page background; the SVGs are illustrations, not a custom stylesheet.
